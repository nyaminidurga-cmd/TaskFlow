# TaskFlow

A smart task planner for daily tasks and reminders.

## About

TaskFlow helps users organize their daily tasks, set reminders, and track their progress in one simple interface.

## Features

- Create and manage tasks
- Set task reminders
- Track pending and completed tasks
- Mark tasks as permanently finished
- Search tasks
- Dark mode
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
